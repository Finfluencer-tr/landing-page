## 🌌 The Antigravity Concept

In a financial world filled with noise, scams, and endless "moon" calls, gravity pulls everything down to reality eventually. **Finfluencer Leaderboard** is the zero-gravity chamber where only the truth floats to the top.

We use **AI Agents** to scrape, analyze, and verify financial predictions against real market data (Binance, Yahoo Finance). The result? A definitive, unshakeable **Credibility Score** for every influencer.

## ✨ Features

- **Zero-G UI**: A fully immersive, physics-based "Antigravity" interface using Framer Motion.
- **Real-Time Sentiment**: "Live Trends" ticker that pulses with the market's collective heartbeat.
- **The Pipeline**: Interactive "How it Works" section demonstrating our AI analysis flow.
- **Global Vision**: Native multi-language support (**English, Türkçe, 中文, العربية**) with RTL support.
- **Modern Tech**: Built on the bleeding edge with Next.js 14 (App Router) and Tailwind CSS v4.

## 🚀 Getting Started

1.  **Clone the command center:**
    ```bash
    git clone https://github.com/Finfluencer-tr/landing-page.git
    cd landing-page
    ```

2.  **Ignite the engines:**
    ```bash
    pnpm install
    ```

3.  **Launch:**
    ```bash
    pnpm run dev
    ```

4.  **Visit Mission Control:**
    Open [http://localhost:3000](http://localhost:3000)
